																		# Myth Wars ReadMe 
	
	1) Öffne die Index Seite. 
	
	
	2) Drücke auf Spiel Starten.
	
	
	3) Spielablauf:
		
		3.1.a) Steuerung erfolgt durch Mausklicks 
	
		3.2.a) Die Karten die du auf die Hand bekommst sind anklickbar um sie auf die Bank oder ins Angriffsfeld zu legen.		
		3.2.b) Klicke eine Karte an, um sie auf die Bank oder ins Angriffsfeld, (durch klick auf besagtes Feld) zu legen.		
		3.2.c) Im ersten Zug ist Angreifen UNMÖGLICH !!!!
		3.2.d) Um, ab dem 2. Zug anzugreifen klickst du auf die Karte im Angriffsfeld.
		3.2.e) Wenn der Angriff erfolgt ist, auf den Button Zug beenden drücken.
		
		Danach ist der nächste Spieler dran.
